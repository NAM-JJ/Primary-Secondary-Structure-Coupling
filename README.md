# Seismic Acceleration Amplification Factors Prediction Model Considering Primary–Secondary Structure Coupling Based on Interpretable Machine Learning
This repository provides the datasets and Python implementation of the Neural Additive Model with Pairwise Interactions (NAM-PI) developed to predict seismic acceleration amplification factors of nonstructural components considering dynamic coupling effects.  
# Computational Environment  
The software environment is as follows:  
Python 3.9.23  
numpy 1.26.4  
pandas 2.3.3   
torch 1.13.1  
Jupyter Notebook
# Datasets  
The repository contains the following datasets:  
traindata.xlsx: Training dataset  
valdata.xlsx: Validation dataset  
testdata.xlsx: Test dataset for different primary structural periods  
testdata2.xlsx: Additional test dataset for different mass ratios
